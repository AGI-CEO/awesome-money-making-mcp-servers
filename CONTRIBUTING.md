# Contributing to Awesome Money-Making & Business MCP Servers

Thank you for contributing! Every MCP server in this directory must have a clear **business, revenue, marketing, sales, e-commerce, SEO/GEO, or agency operations** use case.

## Entry Format

Please follow the standard single-line format:

```markdown
- [owner/repo-name](https://github.com/owner/repo-name) [![owner/repo-name MCP server](https://glama.ai/mcp/servers/owner/repo-name/badges/score.svg)](https://glama.ai/mcp/servers/owner/repo-name) 📇 ☁️ 🍎 🪟 🐧 - Clear 1-sentence description of what the server does and its business/revenue impact.
```

## Pull Request Checklist
- [ ] The repository is public and implements the Model Context Protocol (MCP).
- [ ] The description clearly states the business, marketing, sales, or monetization use case.
- [ ] If you find this list helpful, please ⭐ **Star the repository** to help more founders and developers discover it!
